# ♟️ Twist Chess Pro

**Twist Chess** is a modern, feature-rich, and beautifully designed web-based chess application built with pure HTML, CSS, and JavaScript. It features a complete chess rules engine, glassmorphism UI, customizable themes and pieces, synthesized sound effects, timers, and move histories.

---

## ✨ Features

* **Complete Chess Engine:** Full move validation, check/checkmate detection, stalemate, castling, en passant, and pawn promotion.
* **Modern UI & Animations:** Sleek glassmorphism design, smooth piece movement, legal move indicator highlights, and check animations.
* **Audio Synthesizer:** Built-in Web Audio API sound effects for moves, captures, checks, and game victories without external audio dependencies.
* **Customization Settings:**
  * **Board Themes:** Classic Wood, Ocean Blue, Midnight Dark, and Emerald Forest.
  * **Piece Styles:** Switch between Standard Unicode symbols and Bold glyph sets.
* **Game Utilities:** 
  * Selectable time controls (Blitz, Rapid, and Unlimited) with live countdown timers.
  * Move history ledger tracking standard algebraic notation (SAN).
  * Move undo functionality and board flipping.

---

## 🛠️ Built With

* **HTML5:** Semantic document structure and layout.
* **CSS3:** Custom properties (CSS variables), Grid/Flexbox layouts, and keyframe animations.
* **JavaScript (ES6+):** Custom chess rules logic, state management, and Web Audio API integration.

---

## 🚀 Getting Started Locally

To run this project on your local machine, follow these simple steps:

1. Clone or download this repository to your computer.
2. Ensure all three core files are in the same directory:
   * `index.html`
   * `style.css`
   * `script.js`
3. Double-click `index.html` or open it using any modern web browser (Chrome, Firefox, Edge, Safari).
